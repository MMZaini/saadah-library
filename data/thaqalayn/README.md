# Thaqalayn Data

This directory contains versioned Saadah data releases generated by `scripts/data`.

- `current.json` points to the active blessed release.
- `releases/<version>/manifest.json` records source provenance, counts, and checksums.
- `releases/<version>/canonical` contains source-oriented canonical records.
- `releases/<version>/runtime` contains app-ready artifacts.

Runtime clients read public artifacts from `public/data/thaqalayn/<version>`, using
`public/data/thaqalayn/current/manifest.json` as the active version pointer.

Update flow:

1. Run `yarn data:update` to crawl `thaqalayn.net` and generate a candidate release.
2. Run `yarn test:data`, `yarn lint`, `yarn tsc --noEmit`, and `yarn build`.
3. Review the manifest and diff before publishing.
4. Roll back by restoring `current.json` and the public manifest to a previous release version.

The crawler is for library/search synchronization and must not be used for AI training.
