# Thaqalayn Data

This directory contains versioned Saadah data releases generated by `scripts/data`.

- `current.json` is the repository-side pointer used by validation and maintenance tooling;
  manual candidate generation can move it before a release is blessed.
- `releases/<version>/manifest.json` records source provenance, counts, and checksums.
- `releases/<version>/canonical` contains source-oriented canonical records.
- `releases/<version>/runtime` contains app-ready artifacts.

Runtime clients read public artifacts from `public/data/thaqalayn/<version>`, using
`public/data/thaqalayn/current/manifest.json` as the active version pointer.

## Update policy

Thaqalayn data is not updated automatically. There is no scheduled crawler, data-update
GitHub Action, or automatic publication path. CI only validates data already committed to the
repository. Every crawl, candidate review, and publication must be initiated and approved by
a maintainer.

The crawler remains available as a manual maintenance tool. Its output is untrusted until a
content review confirms completeness, stable IDs and URLs, book/category/chapter structure,
text integrity, language and grading coverage, provenance, licensing, and release size.

## Manual update flow

1. Run `yarn data:update` to crawl `thaqalayn.net` and generate a candidate release.
2. Note that candidate generation repoints `data/thaqalayn/current.json`, but does not change
   the public runtime by default.
3. Compare the candidate against the currently blessed release. Do not rely on structural
   validation alone or accept unexplained removals, identity churn, duplicate source URLs, or
   text/metadata regressions.
4. Run `yarn test:data`, `yarn lint`, `yarn tsc --noEmit`, and `yarn build`.
5. Review the manifest, checksums, provenance, licensing, repository-size impact, and full
   semantic diff before explicitly publishing a reviewed release.
6. Roll back by restoring both the repository pointer and public manifest to the previous
   blessed release; keep the served runtime and its manifest aligned.

The crawler is for library/search synchronization and must not be used for AI training.
